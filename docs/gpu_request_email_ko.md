## 1. 연구 개요

**목표:** 질환 바이오마커인 **MMP9(기질금속단백분해효소-9, gelatinase B)**에 높은
친화도로 결합하는 **DNA 압타머**를 실험적 스크리닝(SELEX) 없이 **계산적으로 설계**하는
것입니다. 압타머는 항체를 대체할 수 있는 핵산 리간드로 진단·바이오센서·표적치료에
활용되며, 기존 SELEX 방식은 수개월의 반복 실험과 큰 비용이 듭니다.

**방법론(핵심 독창성):** 2025년 발표된 딥러닝 압타머 설계법(AiDTA, 강화학습 기반
fragment 조립)을 분석한 결과, 이 방법의 보상 함수가 **실제 단백질 결합을 보지 않고
2차구조 유사도라는 대리지표만 최적화**하는 한계가 있음을 확인했습니다. 저희는 이
루프에 **실제 단백질–핵산 공동접힘(co-folding) 예측 모델(Boltz-2)을 결합 오라클로
삽입**하여, 생성 모델이 **결합력 자체를 직접 최적화**하도록 개선한 파이프라인을
구축하였습니다. 이는 기존 논문 대비 정확도를 높이는 것을 목표로 합니다.

현재까지 표적 정의, fragment 라이브러리, 2차구조 스코어링, 생성 엔진, 오라클
인터페이스 등 **CPU 단계는 구현·검증을 마쳤으며**(코드: [GitHub 저장소 주소]),
남은 핵심 단계인 **딥러닝 오라클 기반 결합 예측·최적화·구조 정밀화**를 위해 GPU가
필요합니다.

## 2. GPU가 필요한 이유 (논리적 근거)

1. **공동접힘 오라클(Boltz-2 / Chai-1):** 생성된 각 압타머 후보를 MMP9와 함께 3D로
   접어 인터페이스 신뢰도(ipTM/PAE)를 계산합니다. AlphaFold3 계열 모델로, **GPU
   없이는 실행이 불가능**합니다. 이 계산이 생성 루프의 보상으로 반복 호출되므로 GPU
   처리량이 프로젝트 속도를 좌우합니다.
2. **분자동역학(MD) + MM/GBSA 자유에너지 계산:** 상위 후보의 결합 자유에너지를
   정량 랭킹하는 단계로, GPU 가속(OpenMM/Amber)이 필수적입니다.

## 3. 요청 사양 및 근거

- **1순위: NVIDIA A100 (40GB) 1장**
- **대안: NVIDIA RTX A6000 (48GB) 1장**

**근거:**
- **메모리:** 공동접힘 모델의 GPU 메모리는 토큰 수(단백질 잔기 + 핵산 염기)의 **제곱
  (N²)** 으로 증가합니다. 저희 복합체는 MMP9 촉매 도메인(약 170–450 잔기) + DNA
  압타머(약 30–60 염기) 규모로, 실측 VRAM 요구량이 **24–40GB** 구간입니다. 따라서
  **40GB(A100) 또는 48GB(A6000)** 가 안정적 최소 사양이며, 16GB급(T4)은 메모리
  초과로 실행이 불가합니다.
- **아키텍처:** A100·A6000는 Ampere 세대로 **bf16 연산을 지원**하여 해당 모델의
  수치 안정성과 속도에 유리합니다(구세대 P40는 텐서코어 미탑재로 부적합).
- **정리:** 센터 보유 장비 중 **A100(40GB)** 이 속도·메모리·아키텍처 균형이 가장
  뛰어나 최적이며, 더 큰 메모리 여유가 필요할 경우 **A6000(48GB)** 도 적합합니다.

## 4. 예상 사용 규모

- **사용 기간:** 약 [2–3]개월 (파일럿)
- **예상 GPU 사용량:** 공동접힘 후보 평가(반복당 수천 건) + 상위 후보 MD/MM-GBSA를
  포함하여 **총 약 300–500 GPU-시간** 내외로 추정합니다.
- **동시 사용:** 기본적으로 **GPU 1장**으로 충분하며, 가능하다면 배치 처리량 향상을
  위해 간헐적 2장 사용을 희망합니다.
- **기타:** 시스템 메모리 64GB 이상, 저장 공간 약 500GB–1TB(모델 가중치·중간 구조
  파일)면 충분합니다.

컴퓨팅 자원의 사용 협조를 정중히 요청드리고자 서신 드립니다.

## 1. 연구 개요

본 연구는 질환 바이오마커인 **MMP9(기질금속단백분해효소-9, gelatinase B)**에 높은
친화도로 결합하는 **DNA 압타머**를, 실험적 스크리닝(SELEX) 없이 **계산적으로
설계**하는 것을 목표로 합니다. 압타머는 항체를 대체할 수 있는 핵산 리간드로서
진단·바이오센서·표적치료에 폭넓게 활용되나, 기존 SELEX 방식은 수개월에 걸친 반복
실험과 상당한 비용을 수반합니다. 본 연구는 이를 **인공지능 기반 설계로 대체**하여
비용과 기간을 획기적으로 단축하는 것을 지향합니다.

방법론의 독창성은 다음과 같습니다. 2025년 발표된 딥러닝 압타머 설계법(AiDTA,
강화학습 기반 fragment 조립)을 면밀히 분석한 결과, 해당 방법의 보상 함수가 **실제
단백질 결합을 고려하지 않고 2차구조 유사도라는 대리지표만을 최적화**하는 구조적
한계를 지님을 확인하였습니다. 이에 본 연구실은 설계 루프 내부에 **단백질–핵산
공동접힘(co-folding) 예측 모델(Boltz-2)을 결합 오라클로 직접 삽입**하여, 생성 모델이
**결합력 자체를 최적화**하도록 개선한 파이프라인을 설계·구축하였습니다. 이는 선행
연구 대비 예측 정확도의 향상을 목표로 하는 방법론적 진전입니다.

현재 표적 정의, fragment 라이브러리, 2차구조 스코어링, 생성 엔진, 오라클 인터페이스
등 **CPU 기반 단계의 구현과 검증을 완료**하였으며(코드 및 문서: [GitHub 저장소
주소]), 연구의 핵심에 해당하는 **딥러닝 오라클 기반 결합 예측·최적화 및 구조 정밀화
단계**를 수행하기 위하여 GPU 자원이 필요한 상황입니다.

## 2. GPU 자원이 필요한 사유

1. **공동접힘 오라클(Boltz-2 / Chai-1):** 생성된 각 압타머 후보를 표적 단백질 MMP9와
   함께 3차원으로 접어 결합 인터페이스의 신뢰도(ipTM/PAE)를 산출합니다. 이는
   AlphaFold3 계열의 대규모 모델로 **GPU 없이는 실행이 불가능**하며, 설계 루프의
   보상 함수로 반복 호출되는 만큼 GPU 처리량이 연구 진척을 직접적으로 좌우합니다.
2. **분자동역학(MD) 및 MM/GBSA 자유에너지 계산:** 상위 후보의 결합 자유에너지를
   정량적으로 랭킹하는 단계로서 GPU 가속(OpenMM/Amber)이 필수적입니다.

## 3. 요청 사양 및 근거

- **1순위: NVIDIA A100 (40GB) 1기** / **대안: NVIDIA RTX A6000 (48GB) 1기**

**근거:**
- **메모리 요구량:** 공동접힘 모델의 GPU 메모리 사용량은 토큰 수(단백질 잔기 + 핵산
  염기)의 **제곱(N²)** 에 비례하여 증가합니다. 본 연구의 복합체는 MMP9 촉매 도메인
  (약 170–450 잔기)과 DNA 압타머(약 30–60 염기)로 구성되어 실측 VRAM 요구량이
  **24–40GB** 수준이며, 따라서 **40GB(A100) 또는 48GB(A6000)** 가 안정적 실행을 위한
  최소 사양입니다(16GB급 T4는 메모리 초과로 실행 불가).
- **연산 아키텍처:** A100·A6000는 Ampere 세대로 **bf16 연산을 지원**하여 해당 모델의
  수치 안정성과 처리 속도 측면에서 유리합니다(구세대 P40는 텐서코어 미탑재로
  부적합). 센터 보유 장비 중 **A100(40GB)** 이 속도·메모리·아키텍처의 균형 면에서
  가장 적합하며, 더 큰 메모리 여유가 필요한 경우 **A6000(48GB)** 도 대안이 됩니다.

## 4. 예상 사용 규모

- **사용 기간:** 약 [2–3]개월 (파일럿 단계)
- **예상 사용량:** 공동접힘 기반 후보 평가(반복당 수천 건)와 상위 후보의 MD/MM-GBSA
  계산을 포함하여 **총 약 300–500 GPU-시간** 내외로 추정합니다.
- **동시 사용:** 기본적으로 **GPU 1기**로 수행 가능하며, 처리량 향상을 위해 가능한
  범위에서 간헐적 2기 사용을 희망합니다.
- **부대 사양:** 시스템 메모리 64GB 이상, 저장 공간 500GB–1TB 수준이면 충분합니다.

경제적으로 설계**하는 파이프라인을 확보하게 되며, 이는 진단·바이오센서를 포함한

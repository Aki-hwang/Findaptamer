# 오라클 캘리브레이션 1차 결과 — Boltz-2 ipTM은 사용 불가

날짜: 2026-08-01 · 실행: Slurm job 3404(1 seed), 3406(5 seeds) · GPU: RTX A6000 (sv4ka-n3)
수용체: MMP9 촉매 도메인 337 aa (UniProt P14780, 107–443) · MSA 캐시 사용

## 결과

| 항목 | 1 seed | **5 seeds** |
|---|---|---|
| 양성 F3B (Kd ~20 nM) | 0.3703 | **0.3388** |
| 음성 평균 | 0.3654 | **0.3418** |

## 결정적 관찰 — 잡음이 신호를 33배 압도

시드만 바꿨을 때 **같은 서열**의 점수 변동:

| 서열 | 5회 측정 | 범위 |
|---|---|---|
| polyA | 0.3972 / 0.3374 / 0.3393 / 0.2177 / 0.3900 | **0.179** |
| random0 | … 0.3398 / 0.3978 / 0.2680 | **0.289** |

- 양성–음성 차이 **0.003**
- **신호/잡음 = 0.03**

즉 이 측정값은 **결합에 관한 정보를 거의 담고 있지 않습니다.**

## 해석

이 결과는 문헌과 일치하며, 그것을 **정량화**합니다. ACS Synth. Biol. 2025(5c00196)는
AlphaFold3가 압타머 *구조*는 잘 예측하지만 *"screening cases에서 유망한 압타머를 식별하는
데 실패한다"*고 보고했습니다. 저희 데이터는 그 **원인**을 수치로 보여줍니다 —
판별 신호(0.003)가 모델 자체의 실행 간 분산(σ=0.10)에 완전히 묻힙니다.

**이 발견은 양성 대조군의 타당성과 무관하게 성립합니다.** F3B가 잘못 모델링됐거나
촉매 도메인에 붙지 않더라도, **시드 간 분산은 모델의 성질**이지 리간드의 성질이 아닙니다.

## 게이트의 가치

캘리브레이션 게이트가 없었다면 8라운드 × 96후보로 **잡음을 최적화**하고, 그럴듯한
랭킹을 만들어 압타머를 합성했을 것입니다. FAIL 판정이 이를 막았습니다.
**음성 결과를 정직하게 보고하는 장치가 실제로 작동했습니다.**

# 2차: 포즈 재현성도 실패 (job 3407, 4서열 × 5시드)

| 항목 | 값 |
|---|---|
| **양성 F3B within-Jaccard** | **0.0** |
| 음성 within-Jaccard | 0.48 |
| 서열 간(between) Jaccard | 0.351 |
| **특이성 마진** | **0.009** |
| 판정 | **NOT SPECIFIC + NOT DISCRIMINATIVE** |

## 관찰

1. **F3B의 시드 간 접촉 집합 겹침이 0입니다.** 같은 서열·같은 수용체인데 5회 예측이
   서로 **완전히 다른 표면**을 지목했습니다. 모델이 이 리간드를 어디에 놓을지
   전혀 모른다는 뜻입니다.
2. **무작위/셔플 대조군이 오히려 더 일관됩니다(0.48).** 그러나 서열 간 일치도가
   0.351이므로, 이는 특정 리간드를 인식해서가 아니라 **일반적인 끈끈한 표면**으로
   몰리는 것입니다.
3. **특이성 마진 0.009** — 어떤 서열을 주는지가 결합 위치를 거의 결정하지 않습니다.

## 결론

**두 판독값(스칼라 ipTM, 접촉 포즈)이 모두 실패했습니다.** 1차에서 점수가 잡음에
묻힌 것이 "요약 통계의 한계"였다면, 2차는 **예측 자체가 리간드를 구분하지 못한다**는
더 근본적인 실패입니다.

Boltz-2 공동접힘을 **이 시스템(MMP9 촉매 도메인 + 36-nt 핵산)의 결합 오라클로
사용하는 방법은 닫혔습니다.**

## 아직 남은 결정적 교란 — 다음 실험으로 분리해야 함

**F3B가 촉매 도메인에 결합한다는 근거가 없습니다.** 문헌에 결합 부위가 미상입니다.
만약 F3B가 hemopexin 도메인이나 전장 구조를 필요로 한다면, 저희는 모델에게
**"이 압타머가 결합하지 않는 도메인에 어떻게 결합하는가"**를 물은 셈이고,
"모른다(=매번 다른 답)"는 **정확한 대답**일 수 있습니다.

따라서 다음 두 가지를 구분해야 결론이 확정됩니다:

- (a) Boltz-2가 **단백질–핵산 복합체 일반**을 못 다루는가?
- (b) **이 특정 조합(비정준 압타머 + 잘못된 도메인)**만 못 다루는가?

### 권장 대조실험 (저비용·결정적)

**정준 단백질–DNA 복합체를 양성 대조로 넣는다.** 예: Zif268 zinc finger–DNA
(PDB 1AAY, ~90 aa + 10 bp) — 고전적이고 고품질이며 학습 데이터에 확실히 포함.

| Zif268 결과 | 해석 |
|---|---|
| 재현성 **높음** | 파이프라인·모델 정상 → 실패는 **압타머/도메인 특이적** (b) |
| 재현성 **낮음** | 설정 또는 모델 자체 문제 (a) → 원인 재점검 필요 |

이 대조가 있어야 "공동접힘은 압타머 선별에 부적합하다"는 주장이 **엄밀해집니다.**
없으면 리뷰어가 즉시 "당신 파이프라인이 틀린 것 아닌가"라고 물을 것입니다.

비용: 1서열 × 5시드, 약 7분 (Zif268은 작아서 빠름).

# 3차: 정준 대조 통과 — 음성 결과가 확정되다 (job 3408, 1AAY × 5시드)

Zif268 zinc finger–DNA 이중가닥(PDB 1AAY, 단백질 90 aa + DNA 11 bp × 2가닥)을
**동일한 코드·모델·GPU**로 같은 검사에 통과시켰습니다.

| 지표 | **Zif268 (정준)** | **MMP9 + F3B (압타머)** |
|---|---|---|
| ipTM 평균 | **0.9743** | 0.3388 |
| **ipTM 표준편차** | **0.0007** | **0.1004** |
| **포즈 재현성(Jaccard)** | **0.974** | **0.0** |
| 판정 | **PIPELINE OK** | FAIL |

**분산 비율 143배.** 포즈는 완전 재현(0.974) 대 완전 무작위(0.0).

## 이것이 확정하는 것

동일한 파이프라인이 정준 단백질–DNA 복합체에서는 **거의 완벽하게** 작동합니다
(ipTM 0.974, 시드 간 편차 0.0007 — 소수점 넷째 자리에서만 흔들림).
따라서 MMP9–압타머에서의 실패는:

- ❌ 코드 결함이 아니고
- ❌ 설정 오류가 아니고
- ❌ GPU/커널 문제가 아니고
- ✅ **압타머–단백질 영역 자체의 예측 실패**입니다

리뷰어의 첫 질문("파이프라인이 틀린 것 아닌가")에 **정량적으로 답할 수 있게
되었습니다.**

## 확정된 발견 (3단 논증)

1. **AiDTA의 대리보상은 결합을 측정하지 않는다** — 구조가 전혀 없는 서열이
   2차구조 유사도 1.0(만점)을 획득함을 실증(`docs/01`, `src/generator/assembler.py`).
2. **그 대안인 공동접힘 오라클도 압타머에서는 작동하지 않는다** — 점수는 신호/잡음
   0.03, 포즈는 재현성 0.0. 알려진 20 nM 결합체가 무작위보다 낮게 평가됨.
3. **그러나 모델 자체는 정상이다** — 정준 복합체에서 ipTM 0.974±0.0007, 포즈 0.974.

→ **결론: 현행 AI 압타머 설계법의 보상 신호는, 대리지표든 공동접힘이든, 압타머
결합을 측정하지 못한다.** 이는 방법론의 한계이지 구현의 문제가 아니다.

## 왜 이런 차이가 나는가 (가설, 검증 필요)

정준 단백질–DNA 복합체(전사인자–operator 등)는 PDB에 풍부하나, **압타머–단백질
복합체는 수십 건 수준**으로 희소합니다. 모델이 전자는 학습했고 후자는 학습하지
못했을 가능성이 큽니다. 이 가설은 PDB 통계로 정량화할 수 있습니다(향후 작업).

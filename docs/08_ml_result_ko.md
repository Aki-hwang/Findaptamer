# 서열 기반 ML — 새 표적에는 작동하지 않는다 (세 번째 음성 결과)

날짜: 2026-08-01 · 전부 CPU · 코드 `src/ml/` · 원자료 `results/ml_*.json`

## 배경

공동접힘이 확정 종료된 뒤(`docs/06` 4차, job 3410) 남은 경로는 서열 기반 ML
하나였습니다. "랜덤 40-nt를 넣고 SELEX처럼 라운드를 돌려 MMP-9 결합체를 ML로
선별한다"가 목표입니다.

데이터는 GitHub에서 구했습니다(egress가 GitHub는 허용):
[AptaNet](https://github.com/nedaemami/AptaNet) (특징 3,404 페어),
[AptaTrans](https://github.com/pnumlb/AptaTrans) (**원서열** 2,900 페어).

## 관문 1·2 — 통과

| 검사 | 질문 | 결과 |
|---|---|---|
| `ablation.py` | 모델이 **단백질**을 읽는가 | **통과** |
| `ood_random.py` | **랜덤 40-mer**를 진짜 결합체와 구분하는가 | **통과** |

단백질 특징을 제거하면 AUROC 0.728 → **0.510(우연)**, 섞으면 0.516.
즉 protein-blind가 아닙니다. 그리고 홀드아웃 단백질 159개에서 진짜 결합체 vs
새로 생성한 랜덤 40-mer가 **AUROC 0.757**로 갈립니다.

부수 발견: **랜덤분할 0.954 vs 압타머그룹분할 0.728.** 논문들이 보고하는 91%대
성능은 같은 압타머가 train/test 양쪽에 들어간 **누출**입니다(압타머당 평균 4.2 페어).

## 관문 3 — 실패. 그리고 이게 결정적이다

앞의 두 관문은 필요조건일 뿐이었습니다. 진짜 질문은 **"처음 보는 단백질로
일반화되는가"**입니다. MMP-9는 이 코퍼스에 없기 때문입니다.

### MMP-9 부재 확인 (엄밀히)

처음엔 `PRCGVPD`(프로도메인 모티프)만 검색했는데, 데이터셋 단백질이 **도메인
조각**일 수 있어 부적절했습니다. 다시 검사했습니다:

| 검사 | 결과 |
|---|---|
| 정확한 부분서열 (양방향) | 0 |
| **MMP-9와 공유하는 10-mer 비율** | **144개 단백질 전부 0.000** |
| MMP9 아연결합부위 `HELGHALGLDHS` | 0 |
| cysteine switch `PRCGVPD` | 0 |
| MMP2 아연결합부위 | 0 |

**MMP-9는 144개 중 어느 단백질과도 10잔기 창 하나 공유하지 않습니다.**
MMP 계열 자체가 코퍼스에 없습니다.

### 단백질 그룹 분할 결과

인코더를 저희가 통제했습니다(압타머 k-mer 340 + 단백질 conjoint triad 343).
AptaNet의 사전추출 특징을 쓰지 않은 이유: 저자 PseAAC 인코더가 재현되지
않습니다(조성 항에 음수, Python 2 정수나눗셈 모호성). 인코더를 소유하면
훈련 단백질에 한 처리를 MMP-9에도 **동일하게** 적용할 수 있습니다.

| 분할 | AUROC | sd |
|---|---|---|
| random (논문들이 보고하는 값) | 0.763 | 0.017 |
| aptamer_grouped | 0.832 | 0.035 |
| **protein_grouped (= MMP-9 상황)** | **0.210** | 0.035 |

**0.210입니다. 우연(0.5)보다 훨씬 낮고, 5개 폴드에서 일관됩니다.**

### 왜 뒤집히는가 — 벤치마크 구성의 결함

| 항목 | 값 |
|---|---|
| 양성이자 음성으로 등장하는 압타머 | **687 / 709 (97%)** |
| 압타머당 평균 양성 수 | **1.02** |
| 압타머당 평균 페어 수 | 4.09 |

각 압타머는 **정확히 한 단백질에 대해서만** 양성이고 나머지엔 음성입니다.
따라서 **"이게 진짜 압타머인가"는 라벨 정보를 전혀 담지 않습니다** — 코퍼스의
모든 압타머가 진짜입니다. 학습 가능한 신호는 **특정 압타머↔단백질 짝**뿐입니다.

처음 보는 단백질에는 그 짝이 존재하지 않습니다. 모델은 다른 데서 배운 짝에
기대는데, 홀드아웃 단백질에서 그 짝은 **정확히 틀린 답**입니다. 그래서 순위가
0.5로 무너지는 게 아니라 **반전**됩니다.

## 결론

**이 부류의 서열 기반 모델은 새 표적을 예측할 수 없습니다.** 본 적 있는 단백질
사이를 보간할 뿐입니다. MMP-9는 코퍼스에 없으므로, 이 모델로 in-silico SELEX를
돌리면 랜덤보다 **나쁘게** 선별합니다.

이는 모델링 버그가 아니라 **데이터 한계**입니다. 단백질이 144종뿐이고, 음성이
무작위 재짝짓기로 만들어졌습니다.

## 세 개의 음성 결과가 하나의 논지로 모인다

| # | 방법 | 결과 | 근거 |
|---|---|---|---|
| 1 | AiDTA 대리보상(2차구조 자기유사도) | **퇴화** | 구조 없는 서열이 만점 1.00 (`docs/01`) |
| 2 | Boltz-2 공동접힘 | **잡음 지배** | 독립 양성 2개가 **둘 다 무작위 이하**; 정준 대조군은 ipTM 0.974±0.0007 (`docs/06`) |
| 3 | 서열 기반 API 분류기 | **새 표적에서 반전** | protein-grouped AUROC **0.210** |

→ **현행 AI 압타머 설계법의 보상 신호는 — 대리지표든, 공동접힘이든, 학습된
서열 분류기든 — 새로운 표적에 대한 결합을 측정하지 못한다.**

세 실패가 각각 다른 이유로 일어났다는 점이 중요합니다. 구현 문제가 아니라
**공통의 근본 한계**입니다: 표적 특이적 실험 데이터가 없으면 결합을 계산할
방법이 없습니다.

## 그래서 MMP-9 서열은 어떻게 얻는가

계산만으로는 얻을 수 없다는 것이 위 세 결과의 결론입니다. 실행 가능한 경로:

```
[완료] G4 사전확률로 집중 라이브러리 설계 (results/g4_library_v1.csv, v2)
          4^40 → 2,000 서열. 결합 예측은 한 번도 하지 않음.
             ↓
[필요] 습식 SELEX 1라운드 + 라운드별 시퀀싱
          ← 여기서 처음으로 MMP-9 특이적 데이터가 생김
             ↓
[가능] 그 데이터로 RaptRanker/DeepAptamer급 학습 → in-silico 라운드 반복
          DL-SELEX 보고: 최대 450배 친화도, 라운드 80% 단축
```

핵심: 저희가 못 하는 것은 **결합 예측**이고, 할 수 있는 것은 **탐색공간 축소**
(4^40 ≈ 10^24 → 2,000)입니다. 축소는 전부 계산·검증 가능한 양으로만 이뤄집니다
(G4 형성 성향, 접힘 자유에너지, TBA 유사도 순열검정, 합성 적합성, 다양성).

# Boltz-2 공동접힘 오라클 상세 설명 (한글)

이 문서는 우리 파이프라인의 핵심 부품인 **Boltz-2 공동접힘(co-folding) 오라클**이
무엇이고, 어떻게 "결합 점수"를 만들며, 왜 AiDTA의 대리보상보다 정확한지를 설명한다.
구현은 `src/oracle/boltz2.py`.

## 1. Boltz-2가 뭔가

- **AlphaFold3(AF3)를 재현·확장한 오픈소스 생체분자 구조예측 모델** (2025).
- 단백질·**DNA·RNA**·리간드·이온을 **한꺼번에** 입력받아 복합체 3D 구조를 예측.
- **MIT 라이선스 → 상업 사용 가능** (AF3는 비상업). 그래서 제품화 스택으로 채택.
- Boltz-2에는 결합력(affinity) 예측 헤드도 있지만 **소분자 전용**이라, 핵산
  압타머에는 쓰지 않고 **구조/인터페이스 신뢰도**를 결합 신호로 쓴다.

## 2. "공동접힘(co-folding)"이 도킹과 뭐가 다른가

- **도킹(HDOCK/HADDOCK)**: 이미 만들어진 두 강체(단백질, 압타머)를 **맞춰 끼우는**
  방식. 압타머의 유연성·유도적합(induced fit)을 잘 못 다루고, 작은 조각일수록
  점수가 부정확·비특이적.
- **공동접힘**: 단백질과 DNA를 **동시에 접으면서 배치**한다. 결합하며 서로 구조가
  바뀌는 것을 모델이 함께 예측 → 압타머–단백질 인터페이스에 더 적합.
- AiDTA는 이 단계가 아예 없었고(생성 중엔 CPU 2차구조만), 도킹은 맨 끝 필터에서만
  썼다. 우리는 **공동접힘을 생성 루프 안으로** 가져온다.

## 3. 입력과 출력

**입력** (`src/oracle/boltz2.py`가 YAML로 자동 생성):
```yaml
version: 1
sequences:
  - protein:            # MMP9 수용체 (촉매 도메인 서열)
      id: A
      sequence: <MMP9 catalytic domain>
      msa: <선택: 미리 만든 단백질 MSA>
  - dna:                # 후보 압타머
      id: B
      sequence: TCTGTCTGGG...   # 우리가 생성한 DNA
```
실행: `boltz predict input.yaml --use_msa_server` (또는 미리 만든 MSA 사용).

**출력**: 복합체 PDB 구조 + `confidence_*.json` (신뢰도 지표들).

## 4. 어떤 지표로 "결합"을 판단하나

공동접힘 모델의 신뢰도 지표는 결합 여부와 직결된다:

| 지표 | 의미 | 결합 관련성 |
|---|---|---|
| **pLDDT** | 잔기별 국소 신뢰도(0–100) | 각 부분이 잘 접혔는가 |
| **PAE** | 두 잔기 상대위치의 예상오차(Å) | **체인 간 PAE가 낮음 = 상대 배치 확신 = 인터페이스 실재 가능성↑** |
| **pTM** | 전체 접힘 품질(TM-score 예측) | 복합체 전체 품질 |
| **ipTM** | **인터페이스 pTM** — 체인들의 상대 배치 확신도 | **결합의 핵심 스칼라** |
| **chain-pair ipTM** | 특정 두 체인(단백질 A ↔ DNA B) 쌍의 ipTM | **가장 순수한 인터페이스 신호** |

우리 오라클은 **단백질–DNA chain-pair ipTM**을 최우선으로 쓰고(없으면 전역 ipTM으로
폴백) `[0,1]` 값으로 정규화해 **결합 점수 = 생성기의 보상**으로 넘긴다.
(`Boltz2Oracle._binding_score()` 참고)

## 5. 생성 루프에서의 역할 (왜 논문보다 정확한가)

```
후보 DNA 서열 ──▶ Boltz-2 공동접힘(+MMP9) ──▶ 인터페이스 ipTM ──▶ 보상
      ▲                                                          │
      └────────── 생성기(MCTS/GFlowNet)가 보상 높은 쪽으로 학습 ◀─┘
```
- AiDTA 보상: "내 서열이 fragment 모양대로 접혔나" — **단백질이 없음**. 그래서
  구조 없는 서열이 만점을 받는 퇴화 문제까지 있었다(우리가 실증).
- 우리 보상: "이 서열이 **MMP9의 표적 자리에** 확신 있게 붙나" — **단백질이 보상
  안에 있음**. 생성기가 **binder를 직접 학습**한다.
- 추가로 **FnII 접촉 벌점**(포즈가 활성화 엑소사이트에 닿으면 감점)으로 선택성까지
  유도(결합체 목표에선 MMP2 교차반응 회피용).

## 6. 정직한 한계 (그래서 캐스케이드가 필요)

- **공동접힘 신뢰도는 압타머 선별기로서 "강하지만 노이즈 있음."** AF3 계열이
  압타머 구조는 잘 맞히지만 ipTM으로 좋은/나쁜 binder를 딱 가르진 못한다는 보고
  (ACS Synth. Biol. 2025). → **단일 점수 맹신 금지.**
- 대응: **Stage 4 합의**(AF3 + Boltz-2, 다중 시드로 재접힘 → 일치하는 것만) +
  **Stage 5 물리 계산**(짧은 MD + MM/GBSA ΔG)로 **보정**한다.
- Boltz-2 affinity 헤드는 소분자 전용 → 핵산엔 **구조 신뢰도만** 사용.

## 7. 실무 (사양·속도·캘리브레이션)

- **VRAM**: 이 복합체(MMP9 촉매도메인 + 30–60 nt DNA)에서 **24–40GB**. 24GB(RTX
  4090)가 실용 최소.
- **속도**: 포즈만 예측 시 복합체당 대략 **수 초~수십 초**(H100 기준 ~3–8초).
  루프에서 수천 개 평가가 가능.
- **캘리브레이션(첫 실행 시 필수)**: 알려진 결합체 **F3B(~20 nM)**를 넣으면 높게,
  **랜덤 50-mer**는 낮게 나와야 오라클이 신뢰 가능. 이 기준으로 임계값을 잡는다.

## 8. 절대 점수를 지어내지 않음

`Boltz2Oracle`는 `boltz`가 설치돼 있지 않으면 **에러를 내고 멈춘다**(가짜 점수를
만들지 않음). GPU 워크스테이션에서 `pip install boltz` 후에만 동작한다. CPU
환경(현재)에서는 `StructureProxyOracle`(구조 적합도 사전확률)로 미리 거르고,
GPU가 붙는 순간 Boltz-2로 교체한다.
